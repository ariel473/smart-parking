# Smart Parking License Plate Tracker 🚗

לוח בקרה לשומר בחניון חכם. מצלמת IoT בכניסה מצלמת את לוחית הרישוי של כל רכב ושומרת את התמונה בשרת אחסון. השומר רואה את כל הרכבים שנכנסו בלוח הבקרה.

> מסלול: **Track 1 – Lite** (HTML + Nginx + Apache)

## ארכיטקטורה

```
 דפדפן השומר
     │
     ├── http://localhost:8080 ──► web      (Nginx)  – מגיש את לוח הבקרה (index.html)
     │
     └── http://localhost:8081 ──► storage  (Apache) – מגיש את תמונות הרכבים
                                       │
                                       └── Volume "plates" – התמונות נשמרות גם אחרי down/up
```

| שירות | אימג' בסיס | פורט | תפקיד |
|---|---|---|---|
| `web` | `nginx:alpine` | 8080 | לוח הבקרה לשומר |
| `storage` | `httpd:alpine` | 8081 | שרת אחסון לתמונות המצלמה |

## הרצה

```bash
docker compose up -d --build
```

- לוח הבקרה: http://localhost:8080
- תמונה לדוגמה: http://localhost:8081/plates/car1.jpg

עצירה (הנתונים ב-Volume נשמרים):

```bash
docker compose down
```

## הדגמת Volume (רכב חדש נכנס)

בהתחלה יש בחניון 3 רכבים, והמונה מראה **3 מתוך 4 מקומות תפוסים**.

1. "המצלמה" שומרת תמונה של רכב חדש בשרת האחסון:

   ```bash
   docker compose cp camera/car4.jpg storage:/usr/local/apache2/htdocs/plates/
   ```

2. מרעננים את לוח הבקרה (F5): מופיע רכב 4, המונה עולה ל-**4 מתוך 4**, ומופיעה ההתראה **"החניון מלא!"**.
3. מוחקים ומקימים מחדש את הקונטיינרים:

   ```bash
   docker compose down
   docker compose up -d
   ```

4. מרעננים שוב: רכב 4 עדיין שם והחניון עדיין מלא, כי התמונה שמורה ב-Volume ולא בתוך הקונטיינר.

> ⚠️ לא להריץ `docker compose down -v`: הדגל `-v` מוחק את ה-Volume ואת כל התמונות. משתמשים בו רק כדי להתחיל מאפס.

## CI/CD

בכל `push` רץ ב-GitHub Actions ה-Workflow [`.github/workflows/docker-build.yml`](.github/workflows/docker-build.yml), שבונה את כל האימג'ים (`docker compose build`) ונכשל אם הבנייה נשברת.

## האלמנט האישי שלנו: מונה מקומות והתראת "החניון מלא!"

לחניון יש 4 מקומות. לוח הבקרה לא מחזיק רשימה קבועה של רכבים: קוד JavaScript ב-`web/index.html` מנסה לטעון משרת האחסון את `car1.jpg`, אחר כך את `car2.jpg` וכן הלאה, עד שמגיע לתמונה שלא קיימת (שגיאה 404). כך כל רכב שהמצלמה מוסיפה מופיע לבד אחרי רענון.

- המונה מראה כמה מקומות תפוסים וכמה פנויים, עם פס שמתמלא.
- כשכל 4 המקומות תפוסים, הפס הופך לאדום ומופיעה ההתראה **"⛔ החניון מלא! אין כניסה לרכבים נוספים."**

בחרנו בזה כי זה מה שהשומר באמת צריך לדעת, וכי זה מראה בדמו את ה-Volume בצורה ברורה: החניון נשאר מלא גם אחרי `down` ו-`up`.
